# Windows 11 本机验收 · 2026-11-19

使用 Windhawk 1.7.3，在一台 Windows 11 电脑上用 Wallpaper Engine 真实壁纸和应用窗口背景验证。不是跨系统版本或多显示器兼容性保证。

| 部位 | 观测结果 |
|---|---|
| 开始菜单与分组标签 | 浅色背景使用 `#19191C`，深色背景使用 `#FAFAFC`。菜单打开后改变背景，原字色保持；关闭重开才更新。 |
| 通知中心、日历、快捷设置 | 在深浅壁纸间切换并重新打开后，实际文字控件切换深浅色。展开时不跟随背景变色。 |
| 任务栏 | 在真实亮、暗壁纸上，先记录自动隐藏时的背景，再与确实展开的任务栏同位置比较。持续明亮后下沿加强，切回暗壁纸后回到基础衬色，两种情况下上沿均保持透明。 |
| 左下角音乐面板 | 展开动画和结束后，材质和内容在同一窗口绘制。天气和资源占用可读；此项不等于对每种播放器进行了兼容性测试。 |

已核对上述四个独立 Mod 的安装版本与发布源码：start-style 1.1.3、notifications 4.3.0、taskbar-style 4.5.1、player 1.1.3。

## 文件资源管理器（explorer 1.7.12）

在 Windows 11 深色主题的详细信息视图中，分别单选一个文件和多选两个文件，读取同一文件行选中前后的背景像素。1.7.11 的选中行仅比普通行暗约 3 个灰阶；1.7.12 的单选和多选均呈蓝灰色。此项未覆盖浅色主题或其他视图。
